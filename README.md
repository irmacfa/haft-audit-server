# سامانه انبارگردانی تجهیزات انفورماتیک - فروشگاه‌های زنجیره‌ای هفت

سامانه وبی برای بررسی و انبارگردانی تجهیزات انفورماتیک فروشگاه‌ها، مبتنی بر Node.js و Express.

## قابلیت‌ها

- خواندن تجهیزات متریال سری 9000 از فایل اکسل و حذف موارد تکراری
- جستجوی کد فروشگاه و جستجوی سراسری اموال/سریال
- ثبت وضعیت تک تک تجهیزات (تایید، موجود/فاقد، کد اموال جدید)
- ذخیره موقت و تایید نهایی با قفل کردن انبارگردانی
- **خروجی اکسل (.xlsx) قابل دانلود** بلافاصله پس از ذخیره موقت
- ارسال گزارش نهایی به ایمیل مدیران
- صفحه مانیتورینگ کلیه فروشگاه‌ها (سبز: تکمیل، زرد: در حال انجام، قرمز: در انتظار) به همراه جستجو

## پیشنیازها

- [Node.js](https://nodejs.org/) نسخه 18 یا بالاتر

## نصب و اجرا

```bash
npm install
cp .env.example .env       # سپس مقادیر آن را ویرایش کنید
```

روی ویندوز کافی است `start.bat` را اجرا کنید تا وابستگیها نصب، سرور اجرا و مرورگر باز شود.

به صورت دستی:

```bash
node server.js
```

سپس آدرسهای زیر را در مرورگر باز کنید:

- پنل انبارگردانی: `http://localhost:3000/`
- صفحه مانیتورینگ: `http://localhost:3000/monitoring.html`

## تنظیمات

فایل `.env` (از روی `.env.example` کپی شود):

| متغیر | توضیح |
|---|---|
| `EMAIL_USER` | نام کاربری ایمیل سامانه |
| `EMAIL_PASS` | رمز عبور / App Password ایمیل |
| `PORT` | پورت سرور (پیشفرض 3000) |

## ساختار پروژه

```
server.js            # سرور Express و APIها
public/index.html    # پنل اصلی انبارگردانی
public/monitoring.html # صفحه مانیتورینگ فروشگاهها
public/style.css     # استایل و فونت IRANSansX
public/fonts/        # فایلهای فونت
public/reports/      # گزارشهای اکسل ایجادشده به صورت خودکار توسط سرور
data/                # فایل اکسل ورودی Copy of Book5.xlsx (اضافه شود)
db/audit_db.json     # دیتابیس ذخیره وضعیتها (به صورت خودکار توسط سرور)
```

> فایلهای داخل `data/`، `db/*.json`، `public/reports/` و `.env` به دلایل امنیتی و حجمی در گیت ذخیره نمیشوند.

## APIها

| متد | مسیر | توضیح |
|---|---|---|
| GET | `/api/equipment` | لیست تجهیزات سری 9000 |
| GET | `/api/audit/:plant` | وضعیت انبارگردانی یک فروشگاه |
| POST | `/api/audit/draft` | ذخیره موقت + ایجاد فایل اکسل |
| POST | `/api/audit/finalize` | تایید نهایی، قفل و ایمیل گزارش |
| GET | `/api/audit/report-exists/:plant` | بررسی وجود فایل گزارش |
| GET | `/api/audit/download/:plant` | دانلود فایل اکسل گزارش |
| GET | `/api/monitoring/status` | وضعیت تمام فروشگاهها |
